# AI Event Recommender

An AI-powered event recommendation system I developed during my AI Engineering internship at Astana Hub.

The project was designed to make event discovery and analysis easier by organizing event information and using AI to generate recommendations based on user interests and preferences.

## What it does

The system combines event data processing with an LLM-based recommendation pipeline.

Its main functions include:

- **Event data collection:** Collects event listings and organizes information into a structured format.
- **Data processing:** Cleans and normalizes event information for further analysis.
- **Event analysis:** Analyzes event topics, frequency, and trends.
- **Personalized recommendations:** Uses Retrieval-Augmented Generation (RAG) and language models to identify relevant events based on user preferences, including interests, target audience, format, and region.

The goal was to reduce the need to manually search through event listings and make recommendations more relevant to individual users.

## How it works

The system follows a basic pipeline:

1. Event information is collected from available sources.
2. The collected data is cleaned and stored in a structured database.
3. Relevant event information is retrieved based on the user's request.
4. An LLM processes the retrieved information and generates recommendations.
5. The recommendations are delivered through a Telegram bot interface.
